Verified pseudonymous accounts

What we aim for

Access control

Squad keys & gating

Each squad shares a squad-level key used so message content is not presented as plain text in the product experience without that key context.

  • Design intent: scope access to cohort-shaped boundaries rather than broadcast feeds.
  • Threat review should include key distribution, rotation posture, and human support workflows.

Operator visibility

Explicit, disclosure-consistent

The hosting environment, including database and logs, may access ciphertext and keys during normal operation. SquadRidge does not currently claim that operators are technically unable to read stored messages when moderation, legal process, or incident response requires access.

Mirror language on /security in external materials — avoid “server-blind” or “E2EE” unless the architecture matches.
