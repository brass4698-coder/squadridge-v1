# MENDguild redesign prompt pack

This document contains the full prompt series for revising and redesigning MENDguild into a more impactful, modern, and serious platform for facilitator-led conflict resolution, protected dialogue, and public outcome publication.

The prompts are designed to be pasted into an AI agent one at a time, in order. The current product context includes a public outcome record flow where the session remains private and only the approved outcome is released publicly. [localhost](http://localhost:5173/ledger/demo-proposal-001)

## Prompt 1 — Product reset

```text
You are a world-class product strategist, UX architect, brand designer, and front-end systems thinker.

I need you to completely revise and redesign my platform, MENDguild, so it feels dramatically more impactful, modern, credible, and mission-critical.

This is not a generic SaaS app. It is a platform for facilitator-led, high-stakes, conflict-resolution dialogue. It is built for extremely important conversations involving risk, mistrust, identity sensitivity, and the need to create a public outcome without exposing private room-level discussion.

Core platform idea:
- Private, facilitator-led dialogue rooms
- Verified participant eligibility and trust gating
- Identity protection and anonymity-preserving participation
- Release of public outcome records only
- Ledger-based verification and citation of approved outcomes
- Built for mediators, facilitators, civic leaders, peace-tech operators, researchers, institutions, and partners handling sensitive conversations

The redesign goal:
- Make the platform feel like essential infrastructure for de-escalation, mediation, and serious dialogue
- Remove any feeling of “startup landing page,” “chat app,” “forum,” or “generic community tool”
- Make it feel calm, modern, institutional-grade, ethically serious, and operationally trustworthy
- Design for high-trust, high-consequence use cases
- Emphasize conflict resolution, civilian protection, mediation, dialogue under pressure, and publishable outcomes
- The emotional tone should be: sober, precise, humane, credible, protected, modern

What I want from you in this step:
1. Reframe the product positioning
2. Rewrite the brand strategy
3. Define the core user groups
4. Define the UX principles
5. Define what the platform should feel like visually and emotionally
6. List what must be removed from the current product if it feels too generic, too verbose, too startup-like, too academic, or too weak
7. Output a concise “platform north star”
8. Output 5 alternative positioning statements
9. Output 3 homepage direction options:
   - Institutional / diplomatic
   - Civic / human-centered
   - High-assurance / trust-infrastructure

Important constraints:
- This platform is for sensitive and serious dialogue
- Privacy is operational, not cosmetic
- Public records must feel citable and credible
- Participants should feel protected
- Facilitators should feel in control
- External observers should understand that only approved outcomes are public, never raw room discussion
- Avoid hype language, vague tech clichés, AI clichés, and generic peace platitudes

Write with precision and authority.
```
