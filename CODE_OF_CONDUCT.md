# Code of Conduct

SquadRidge exists to help people have harder conversations more safely. The same spirit applies here.

## The short version

Be honest. Be kind. Disagree productively. Don't make this space unsafe or unwelcoming for others.

## What we expect

**In code and reviews:**
- Critique code, not the person who wrote it. "This approach has a race condition" is fine; "this is terrible" is not.
- If you're unsure about a decision, ask before assuming bad intent.
- Security and privacy issues get reported privately first — see SECURITY.md.

**In discussions and issues:**
- Be direct but considerate. Brief and honest beats polite-but-vague.
- If you're frustrated, take a break before responding. This is a platform for de-escalation; it should model that.
- Disagreement about technical direction is healthy and expected. Personal attacks aren't.

**For everyone:**
- No harassment, discrimination, or intimidation on any basis — full stop.
- No sharing of private information (real names, location, contact details) of contributors without their explicit consent.

## What happens if someone crosses the line

We'll reach out directly and privately first. If the behavior continues or is severe enough to skip that step, we may remove access to the repo or project spaces.

We're a small team; this isn't a formal arbitration process. It's a human one. We'll try to handle things thoughtfully.

## Scope

This applies to the GitHub repo, issue tracker, and any SquadRidge-affiliated spaces (Slack, Discord, etc. if they exist). It does not cover your personal social media or unrelated communities.

## Questions

If you're unsure whether something is okay, just ask. If you see something that doesn't sit right, email us at the address in SECURITY.md.
